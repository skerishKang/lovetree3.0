# LT3-TREE-DETAIL-001 알려진 시각 차이

> 기준 이미지: `community-tree-detail-desktop.png` (2752×1536)
> 구현 화면은 디자인 BASE 단계로, 아래 항목은 VISUAL 트랙에서 정밀 보정 예정.

## 구조적 차이

| 항목 | 기준 이미지 | 구현 | 비고 |
|---|---|---|---|
| 배경 | 파스텔 그라데이션 + 나무 실루엣 장식 | 파스텔 그라데이션만 (나무 실루엣 없음) | 당분간 CSS 그라데이션 유지 |
| 타임라인 카드 | polaroid 스타일 약간 기울어짐 + 종이 질감 | 수평 정렬, 플랫 디자인 | VISUAL에서 스크랩북 감성 추가 |
| 카드 아이콘 | 손그림 스타일 일러스트 | 이모지 문자 사용 | VISUAL에서 SVG 정밀화 |
| 중앙 가지선 | 곡선 + 글로우 노드 | 직선 + 둥근 점 | VISUAL에서 곡선+글로우 적용 |
| 우측 사이드바 | 약 25% 폭, 배경 분리되어 있음 | 320px 고정 폭, border-left로 분리 | 레이아웃 근사치 |

## 타이포그래피

| 항목 | 기준 이미지 | 구현 | 비고 |
|---|---|---|---|
| 제목 폰트 | Pretendard Variable | System-ui fallback | Pretendard 미설치 환경 |
| 설명 line-height | 조밀함 | 1.5 | 2줄 clamp 적용 |
| 작성자 핸들 | 깔끔한 폰트 | 동일 system-ui | 차이 최소 |

## 인터랙션

| 항목 | 기준 이미지 | 구현 | 비고 |
|---|---|---|---|
| 좋아요 버튼 | 클릭 시 토글 | React state 토글 | 시각적 위장 없음, 실제 API 없음 |
| 저장 버튼 | 클릭 시 색상 변화 | state 토글 | text 변경 (저장됨) |
| 댓글 입력 | placeholder | 동일 구현 | 입력 가능, 실제 전송 없음 |

## 의도적 누락 (MyPage DEFERRED)

`/my-page` 경로는 reference 부재로 DEFERRED 상태이며, 추후 reference 확보 후 FUNC 단계에서 작업 예정.

## VISUAL 이관 항목

1. 배경 나무 실루엣 장식
2. 카드 polaroid 기울임/종이 질감
3. SVG 아이콘 정밀화
4. 중앙 가지선 곡선 + 글로우 효과
5. 정확한 폰트 적용 (Pretendard)
6. 그림자/테두리 pixel-level 보정
7. 카드 간 간격 최적화
8. 반응형 브레이크포인트 미세 조정
