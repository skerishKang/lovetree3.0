# LT3-COMMUNITY-001 BASE — 알려진 시각 차이 (VISUAL 이관 항목)

> BASE 단계에서는 pixel-perfect 보정을 하지 않습니다.
> 아래 항목은 정밀 시각 보정(VISUAL 트랙)으로 이관합니다.

## 기준 이미지 대비 주요 차이

1. **Featured LoveTree 배치**
   - 기준: 중앙 tall 카드가 그리드 한가운데 위치 (5열 그리드의 중앙 열 점유)
   - 구현: 하단 별도 블록(좌측 썸네일 + 우측 텍스트)으로 단순화
   - 이관: 중앙 tall 카드 배치로 재구성

2. **카드 그리드 열 수**
   - 기준: 5열 (중앙에 Featured 점유)
   - 구현: 4열 (반응형 3/2/1열), Featured는 별도 블록
   - 이관: Featured를 그리드 내 중앙 열로 통합하는 레이아웃 재설계

3. **배경 나무 실루엣**
   - 기준: 좌우 가장자리 스타일화된 나무 실루엣
   - 구현: 그라데이션만 적용 (실루엣 미표현)
   - 이관: SVG 나무 실루엣 장식 추가

4. **썸네일 보케 패턴**
   - 기준: 콜라주 스타일 썸네일 (여러 이미지 합성 느낌)
   - 구현: 단색 그라데이션 + 재생 아이콘
   - 이관: 콜라주 느낌의 다중 이미지 합성 표현

5. **폰트 렌더링**
   - 기준: Pretendard 또는 유사 폰트의 정밀한 타이포
   - 구현: 시스템 폰트 폴백 (Pretendard 미설치 환경)
   - 이관: 웹 폰트 로딩 및 타이포 세밀 조정

6. **그림자 / 카드 테두리 디테일**
   - 기준: 부드러운 그림자, 미세한 보더
   - 구현:近似 그림자 적용
   - 이관: 정밀 그림자/보더 값 보정

7. **카테고리 메뉴 위치**
   - 기준: 헤더 우측에 인기/최신/입덕/콘서트/직캠/컴백 배치
   - 구현: 검색창 아래 중앙 정렬 chip 행
   - 이관: 헤더 우측 인라인 배치 또는 기준과 동일한 위계 검토

8. **좋아요/댓글 아이콘**
   - 기준: 하트 / 말풍선 아이콘 (벡터)
   - 구현: 유니코드 문자 (♥, 💬) 사용
   - 이관: 인라인 SVG 아이콘으로 교체
