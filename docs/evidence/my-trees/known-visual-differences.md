# LT3-MY-TREES-001 Known Visual Differences

## 기준 이미지

- 기준 이미지 경로: `docs/reference/screens/06-my-trees/my-trees-dashboard-desktop.png`
- 기준 이미지 해상도: `2816 × 1536`
- 기준 이미지 SHA-256: `df3893253f2b1289a99b78245c7d8700ead7ba9cde4e584742134f306ea07814`
- 기준 이미지 유형: 데스크톱 대시보드

## 구현 단계

- 현재 구현 단계: BASE
- 정적 목업 데이터만 사용
- API·Firebase·인증 없음
- 실제 CRUD 없음
- 실제 화면 이동 없음

## 고정 selected 상태 구현 방식

- 단일 진실원천: `selectedTreeId: "tree-1"`
- 각 카드에서 별도 `isSelected` 필드를 두지 않음
- 컴포넌트에서 `const isSelected = tree.id === data.selectedTreeId;`로 계산
- 선택된 카드에만 `data-selected="true"` 및 `aria-current="true"` 부여
- 비선택 카드는 `data-selected="false"`, `aria-current` 없음
- 사용자 클릭으로 선택 변경 불가 (고정 표시만)

## 레이아웃 수치 (실제 CSS 기준)

- 본문 최대 너비: `max-width: 1200px`
- 본문 좌우 패딩: `24px` (데스크톱), `16px` (모바일 ≤560px)
- 트리 카드 그리드: `repeat(auto-fill, minmax(260px, 1fr))`
- 카드 간 간격: `16px`
- 카드 border-radius: `16px`
- 카드 테두리: `1px solid #ede6dc`
- 선택 카드 효과: `border-color: #d96b8f` + `box-shadow: 0 0 0 2px rgba(217, 107, 143, 0.25), 0 4px 16px rgba(42, 38, 34, 0.08)`
- 썸네일 높이: `120px`
- CTA 버튼 border-radius: `10px`
- visibility 배지 border-radius: `999px`

## 데스크톱 해석 방식

- 2단 구조: 좌측 트리 카드 그리드 + 우측 사이드바 (280px 고정)
- 트리 카드는 auto-fill 그리드로 3~4열 배치
- 사이드바는 sticky로 상단 고정
- 헤더는 sticky로 상단 고정

## 모바일 해석 방식

- 900px 이하: 사이드바가 본문 아래로 이동 (단일 열)
- 560px 이하: 트리 카드 단일 열, CTA 전체 너비, 패딩 축소
- 카드 겹침 없음, 수평 스크롤 없음

## 기준 이미지와 다른 부분

1. **카드 수**: 기준 이미지는 6개 카드이나 일부 텍스트가 불명확하여 목업 데이터의 카드 제목·설명을 자연스러운 목업 문구로 대체
2. **썸네일**: 기준 이미지는 이미지 아이콘이 포함된 사각형 박스이나, BASE 단계에서는 그라데이션 색상으로 대체
3. **날짜 형식**: 기준 이미지의 "2023.05.20" 형식을 참고하되, 2025년 목업 날짜로 대체
4. **카드 액션 라벨**: 기준 이미지의 "편집/공유/복제/삭제" 액션을 그대로 사용하되, BASE 단계에서는 비활성 UI만 렌더링
5. **사이드바 항목**: 기준 이미지의 "최근 수정한 순간" 사이드바를 구현하되, 2개 목업 항목만 포함
6. **색상 톤**: 기준 이미지의 따뜻한 베이지/크림 톤을 반영하되, 정밀 색상 매칭은 후속 작업
7. **타이포그래피**: 기준 이미지의 세리프 로고를 Georgia 폰트로 근사 적용

## VISUAL 후속 이관 항목
