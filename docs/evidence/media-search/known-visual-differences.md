## UI BASE 단계

이 구현은 UI BASE 단계로, 실제 검색/미디어 연결 기능 없는 presentation-only 정적 UI입니다.

## 기준 이미지 해석

- 기준 이미지는 중앙의 모바일 폰 프레임과 우측의 2개 부가 설명 패널로 구성됩니다.
- **폰 프레임 내부**를 실제 구현 기준으로 삼았습니다.
- 우측 설명 패널은 상세 요소를 확대 설명하기 위한 부속 자료로, 추가 화면이나 다른 상태를 의미하지 않습니다.

## 모바일 프레임 시안의 통합 방식

- 기준 이미지의 폰 프레임 내부 UI를 그대로 단일 페이지로 구현했습니다.
- 검색창 → 카테고리 필터 → 검색 결과 리스트 순서의 수직 레이아웃입니다.
- 부가 설명 패널의 요소(확대된 카드 보기, 태그 표시 등)는 통합하지 않았습니다.

## 구현 상세

### 실제 검색 없음
- 검색창은 `readOnly` input으로, 실제 검색 기능이 없습니다.
- 검색어 입력/제출/결과 필터링이 동작하지 않습니다.

### 실제 러브트리 추가 없음
- 각 카드의 `러브트리에 추가` 버튼은 `onClick` 없는 UI-only 버튼입니다.
- 클릭해도 아무 동작도 발생하지 않습니다.

### 외부 미디어 연결 없음
- 썸네일은 그라데이션 색상의 정적 placeholder입니다.
- 실제 이미지/동영상 URL을 참조하지 않습니다.
- `<video>`, `<iframe>`, YouTube 관련 요소가 없습니다.

### 정적 썸네일 placeholder
- 각 카드의 썸네일은 CSS linear-gradient로 구현된 색상 블록입니다.
- 색상별 구분: purple, blue, pink, green, brown.

### API·Firebase·인증 없음
- 네트워크 요청, Firebase, localStorage, 인증 관련 코드가 없습니다.

### 카테고리 필터
- 4개의 카테고리 버튼(무대, 직캠, 컴백, 콘서트)을 표시합니다.
- `aria-pressed`, `role="tab"`, `aria-selected`를 사용하지 않은 장식성 UI입니다.
- 실제 필터링 기능은 없습니다.

### 접근성 구조
- 화면 제목: `<h1>미디어 검색</h1>`
- 검색창: `aria-label="미디어 검색"`, `role="searchbox"`
- 카테고리 필터: `role="group"`, `aria-label="카테고리 필터"`
- 결과 리스트: `section > ul > li > article`
- 각 article: `aria-labelledby`로 카드 제목 연결
- 추가 버튼: `aria-label="{title} 러브트리에 추가"`
- 장식 SVG: `aria-hidden="true"`
- `focus-visible` 스타일 적용
- 색상만으로 상태를 표현하지 않음

## Responsive Desktop 해석

- 데스크톱(768px 이상)에서는 모든 콘텐츠 영역이 `max-width: 480px`으로 중앙 정렬됩니다.
- 모바일의 수직 리스트 레이아웃을 유지하며, 과도하게 늘어나지 않도록 제한합니다.
- 별도의 데스크톱 사이드바를 추가하지 않습니다.

## 기준 이미지와 다른 부분

| 항목 | 기준 이미지 | 현재 구현 |
|---|---|---|
| 폰 프레임 외부 요소 | 우측 부가 설명 패널 있음 | 구현 제외 (UI BASE 정책) |
| 실제 디바이스 프레임 | iPhone 스타일 프레임 | 미구현 (웹 페이지) |
| 검색 아이콘 | 돋보기 아이콘 있음 | 미구현 (추가 가능) |
| 카드 내 채널명 아이콘 | 작은 아이콘 있음 | 텍스트만 표시 |
| 배경 | 나무 질감 테이블 | 심플 배경 (#f8f5f0) |
| 썸네일 | 추상 이미지 | 그라데이션 색상 |

## 정밀 VISUAL 후속 작업

- 썸네일에 실제 플레이스홀더 아이콘/이미지 추가
- 검색창에 돋보기 아이콘 추가
- 카드 hover 시 시각적 피드백 개선
- 데스크톱에서 모바일 프레임 효과
- 카테고리 필터 선택 상태 시각 디자인
- 채널명 아이콘 추가
- 전반적인 간격·타이포그래피 미세 조정
